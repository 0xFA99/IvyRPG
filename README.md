A no-nonsense RPG engine written in C using Raylib. Built for speed, designed for chaos.

## What This Thing Does

- **Tilemap System** - Handles your world with autotiling (borders, carpets, tables, walls). Just don't break it.
- **Player Movement & Physics** - Walk around, collide with stuff, deal with it.
- **Collision Detection** - Doesn't let you phase through walls. Mostly.
- **Inventory System** - Carry items. Pick them up. Drop them. Whatever.
- **Scene Management** - Title screen, gameplay, options. The usual suspects.
- **Sprite & Animation** - Draw stuff on screen that moves (sometimes on purpose).
- **Camera System** - Follows your character around like a creepy stalker.
- **Dynamic Allocators** - Linear and pool memory allocation for when you care about performance.

## Build It

**Requirements:**
- CMake 3.20+
- compiler (GCC /Clang)
- custom Raylib (included in `/lib`)

**Build:**
```bash
mkdir build
cd build
cmake ..
cmake --build .
```
**Run:**
```bash
./IvyRPG
```
